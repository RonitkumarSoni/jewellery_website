# Rishav Jewellers — Website Asset Pack

A reference-based asset bundle for recreating the supplied Rishav Jewellers homepage. Visual direction: warm ivory/cream backgrounds, deep maroon typography and footer, antique-gold accents, premium Indian jewellery photography, and classic serif branding.

## Folder map
- `logo/` — screenshot-derived logo crops and editable SVG logo/monogram concepts.
- `banners/` — generated jewellery showroom hero, screenshot-derived heritage/bridal crops, and full-page visual reference.
- `collections/` — category tiles and reference imagery for gold, diamond, bridal, silver, gemstone, men's and kids collections.
- `products/` — featured necklace, bangle, earring and ring product crops, plus reference crops for chains, mangalsutra and pendants.
- `occasions/` — collection/occasion reference artwork.
- `icons/` — simple SVG navigation icons.
- `decorative/` — heritage jewellery-box and lotus motif crops.

## Important notes
1. The supplied file was a flattened screenshot, not the original website source or its original image files. Cropped images are taken from that screenshot; they are useful for matching the visible design but are not original-resolution product photography.
2. `banners/hero-store.png` is a newly generated showroom visual designed to match the screenshot's warm gold-lit store interior. The original screenshot hero crop remains visible in `banners/homepage-reference.png`.
3. The screenshot displays only four product cards and four collection tiles. Additional category folders therefore contain clearly named reference imagery reused from the closest visible screenshot content, not unseen original products.
4. Replace reference crops with real product photography before publishing a live store. Confirm product descriptions, prices, contact details, logo ownership, and store address independently.

## Suggested web paths
Use these files as static assets, e.g. `/assets/banners/hero-store.png`, `/assets/products/necklaces/necklace-featured.png`, and `/assets/icons/search.svg`.
